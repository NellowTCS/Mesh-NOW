Installation Options

When "Preserve node data" is checked, only the application partition is flashed, keeping your settings and saved content.

When unchecked, a complete installation is performed, which erases all data and settings.

Requirements

This tool requires a Chromium-based browser (Chrome, Edge, Opera) with Web Serial API support.

Connect your device via USB and ensure no other program is using the serial port.
